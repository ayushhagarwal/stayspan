# Support

StaySpan is a community-maintained early-stage project.

- Use [GitHub Discussions](https://github.com/ayushhagarwal/stayspan/discussions) for setup help, questions, and product ideas.
- Use [GitHub Issues](https://github.com/ayushhagarwal/stayspan/issues) for reproducible bugs and accepted feature work.
- Use private vulnerability reporting for security or privacy concerns.

Before requesting help, check the README, existing issues, and current limitations. Never post real booking links, confirmation numbers, or personal travel data.
